# Exercise 1 - Building the Knowledge Base

> This is a time-boxed exercise. You are not expected to finish.

## 1. Run `/start-project`

Choose **brownfield**, then:


| Question | Answer |
| -------------------------- | ------------------------------------------------------------------------------------------------------ |
| Flow | **brownfield** |
| The four `*_package` paths | `{project-root}/../electric-wealth-specifications/<stage>` |
| `knowledge_base_path` | `{project-root}/../electric-wealth-knowledge-base` — **no default, type it** |
| Repos | a `code`, a `name`, `path` = `{project-root}/../<electric-wealth-*>`, and a `role` |
| Dedicated QE repo | No |
| Decision-table codes | **Skip** |
| Glossary, change log | Skip or accept defaults |


The paths should come out as:

```toml
[project.paths]
requirements_package = "{project-root}/../electric-wealth-specifications/requirements"
design_package = "{project-root}/../electric-wealth-specifications/design"
implementation_package = "{project-root}/../electric-wealth-specifications/implementation"
quality_package = "{project-root}/../electric-wealth-specifications/quality"
knowledge_base_path = "{project-root}/../electric-wealth-knowledge-base"
```

**Keep the `features.toml` it writes.** Wrong answers can be fixed later by editing `project.toml`.

## 2. Reverse-engineer the repositories

```
/analyze-repository
```

Run the skill(s) it names, **one at a time**.

- **Read the file-structure gate** before you approve it.
- Close out by **attesting**: accept the `automated` verdict, or run `/review-reverse-engineering-package`.

## 3. Build the knowledge base

Either by using the specific commands below or by prompting the agent yourself, build and verify the knowledge base

```
/build-knowledge-base
/verify-knowledge-base-coverage --mode=baseline
```

**Read `electric-wealth-knowledge-base/ARCHITECTURE.md`.** Then commit and push the KB on your branch.

When you are done, you can move on to the next [exercise](./02.md).
